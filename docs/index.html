GitHub Action

Descriptly

Generate image alt text for pull requests using Pollinations vision. Catch missing accessibility descriptions before they merge.

View source Marketplace

Install

- uses: g33ky00/descriptly@v1
  with:
    pollinations-token: ${{ secrets.POLLINATIONS_TOKEN }}
    mode: "comment"

PR comment mode

Suggest alt text directly in PR comments without touching files.

Configurable

Choose image extensions, token, and GitHub token inputs.

Pollinations vision

Uses gen.pollinations.ai vision models to describe images concisely.
